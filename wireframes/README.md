## 🚀 How to Use with AI Wireframe Tools

### Step 1: Choose Your AI Tool
Popular options:
- **Uizard** - uizard.io
- **Figma AI** - figma.com/ai
- **WireframeAI** - Various platforms
- **Midjourney/Stable Diffusion** - For visual mockups
- **Claude AI** - For detailed text descriptions
- **ChatGPT** - For iterative design

### Step 2: Copy & Paste Prompts

**IMPORTANT**: Most AI tools have a 5000 character limit per prompt. Use the parts sequentially.

#### For Complete Wireframes:
1. Start with **Part 1** - paste into AI tool
2. Continue with **Part 2** - "Continue from where you left off"
3. Then **Part 3**, **Part 4**, and **Part 5**
4. Finally: "Generate all 8 screens with navigation flow"

#### For Individual Screens:
Copy only the section you need from any part file.

## 💡 Tips for Best Results

1. **Start with Part 1** and iterate
2. Be specific: "Generate Screen 1: Login with dark theme"
3. Request variations: "Show me the empty state for orders"
4. Ask for exports: "Export as PNG/SVG" or "Generate HTML/CSS"
5. Review and refine: "Make the cards larger" or "Change orange to blue"
